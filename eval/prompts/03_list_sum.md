## Task

Given the list `[3, 1, 4, 1, 5, 9, 2, 6]`, print three lines: the sum,
the length, and the maximum value, in that order.

## Expected output

```
sum=31
length=8
max=9
```

## Notes

Tests list builtins and string interpolation/concat. The `Std` module
has `Std.sum`, `Std.max_by`, but you can also write it recursively.
