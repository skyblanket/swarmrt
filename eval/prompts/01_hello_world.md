## Task

Write the simplest possible sw program that prints exactly `hello, world`
to stdout (no extra punctuation, no trailing newline marker — just the
text plus the implicit newline from `print`).

## Expected output

```
hello, world
```

## Notes

This is the smoke test. Any sw program that compiles and prints the
right line passes. If a model fails here, the rest of the suite is
informational only.
