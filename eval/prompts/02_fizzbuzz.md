## Task

Implement FizzBuzz for numbers 1 through 15. For multiples of both 3
and 5 print `FizzBuzz`; for multiples of 3 print `Fizz`; for multiples
of 5 print `Buzz`; otherwise print the number itself. One line per
number.

## Expected output

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

## Notes

Exercises basic control flow, `%` modulo, `print`, and either
recursion or a `for` loop (`for i in Std.range(1, 16) { ... }` with
`import Std`). Both approaches are valid.
